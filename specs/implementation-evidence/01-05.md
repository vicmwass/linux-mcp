# 01-05 — host trust and destination policy

Implemented `crates/inventory/src/trust.rs` and `src/destinations.rs`.

- Host trust requires a current revision observation, exact fingerprint match, and owner/server/hostname/port scoping. Changed or unverified keys fail closed.
- Destination policy checks allowed ports, every DNS result, blocked infrastructure ranges, explicit self-hosted CIDRs and the actual selected address at connection time.
- Four unit tests cover stale/mismatched enrollment, trust scope, IPv4/IPv6/private/metadata rejection, alternate DNS results and selected-address rechecks.

Checks: `cargo test --offline --locked -p linux-mcp-inventory` — 4 passed; doc tests passed. No live targets or credentials were used. Architecture entry recorded in `linux-mcp-architecture-explanation.md`.
