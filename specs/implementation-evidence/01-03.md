# 01-03 — owner-scoped inventory repository

Implemented `crates/inventory/src/repository.rs` with a PostgreSQL-backed repository that applies installation and owner predicates to list/get/insert/update/disable operations. Pagination uses the stable `(updated_at, server_id)` cursor; expected-revision writes increment the revision and stale/foreign/absent records do not expose cross-owner metadata. The repository is deliberately below the authentication boundary and has no SSH or arbitrary secret-path access.

Checks:

- `cargo check --offline --locked -p linux-mcp-inventory` — passed.
- `cargo test --offline --locked -p linux-mcp-inventory` — passed (crate has no unit tests yet).
- Disposable PostgreSQL concurrency/restart tests are not available in this local environment and remain required before the step's real integration gate.
