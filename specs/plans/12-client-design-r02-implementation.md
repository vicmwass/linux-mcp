# Spec 12 client design revision r02

This supplemental revision refreshes the published `0.1.0` client design without
overwriting it. It uses the existing Spec 12 screens and Stitch project as the
baseline, preserving safety semantics while introducing a calmer operator
workspace visual language.

## Scope

- Baseline: `design/client/versions/0.1.0`
- Draft output: `design/client/revisions/r02`
- Affected surfaces: shared foundations and the local preview shell
- Unchanged: screen semantics, approval binding, state taxonomy, accessibility
  requirements, and backend/runtime contracts

## Checks

Run the revision preview at desktop, tablet, and mobile widths. Verify keyboard
focus, non-color status cues, contrast, reduced motion, bounded data regions,
and that the exact-action approval copy remains unchanged.
